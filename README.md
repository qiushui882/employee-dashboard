# 员工数据提取分析系统

Python + MySQL CLI 员工数据多维度分析工具。

## 功能

| 编号 | 功能 | 技术点 |
|------|------|--------|
| 1 | 总览仪表盘 | COUNT + AVG |
| 2 | 学历分析 | GROUP BY + JOIN |
| 3 | 籍贯分布 | 三表 JOIN |
| 4 | 年龄段分析 | CASE WHEN |
| 5 | 性别比例 | GROUP BY + 百分比 |

## 技术栈

Python 3 · MySQL 8.0 · pymysql · pandas · Linux/WSL2
